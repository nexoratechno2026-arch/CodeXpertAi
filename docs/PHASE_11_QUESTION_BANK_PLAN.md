## 3. Five-Tier Difficulty Standard
1. **Absolute Beginner:** Direct single-concept problems; ideal for students starting their programming journey (e.g., Valid Palindrome, Climbing Stairs, Hamming Weight).
2. **Beginner:** Multi-step procedural logic with standard data structures (e.g., Two Sum, Kadane's Algorithm, Self-Join SQL).
3. **Intermediate:** Common algorithmic patterns requiring optimal time/space complexity (e.g., Search in Rotated Array, Sliding Window Substring, Coin Change DP).
4. **Advanced:** Complex state tracking and combined data structure design (e.g., LRU Cache, Trapping Rain Water).
5. **Expert:** Sophisticated algorithms involving graph transformations or multi-way merging (e.g., Merge K Sorted Streams, Word Ladder, Median of Two Arrays).
